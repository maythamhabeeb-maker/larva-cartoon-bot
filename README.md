# 🎬 AI Cartoon Studio

منصة وكلاء ذكاء اصطناعي تصنع قصصاً كرتونية تلقائياً بالعربية والإنجليزية وترسلها عبر تيليغرام.

---

## 🚀 الإعداد السريع

### 1. تثبيت المكتبات
```bash
pip install -r requirements.txt
```

### 2. إعداد مفاتيح API

انسخ `.env.example` واحفظه باسم `.env`:
```bash
copy .env.example .env
```

ثم افتح `.env` وضع مفاتيحك:
```
GEMINI_API_KEY=AIza...    ← من https://aistudio.google.com
TELEGRAM_BOT_TOKEN=123... ← من @BotFather على تيليغرام
```

### 3. الحصول على Telegram Bot Token
1. افتح تيليغرام وابحث عن `@BotFather`
2. أرسل `/newbot`
3. اختر اسماً للبوت (مثلاً: `MyCartoonBot`)
4. انسخ الـ Token وضعه في `.env`

---

## ▶️ تشغيل البوت
```bash
python bot.py
```

## 🧪 اختبار بدون تيليغرام (CLI)
```bash
python main.py قصة عن قطة تحب الكتب
```

```

├── .env                    ← مفاتيحك (لا ترفعه لـ GitHub!)

├── requirements.txt
├── agents/

│   ├── script_agent.py     ← ✍️ يكتب السيناريو
│   ├── artist_agent.py     ← 🎨 يولد الصور
│   ├── narrator_agent.py   ← 🎙️ يسجل الصوت
│   └── editor_agent.py     ← ✂️ يعمل المونتاج
├── pipeline/
│   └── cartoon_pipeline.py ← ينظم كل الوكلاء
├── tools/
│   ├── gemini_tool.py      ← Gemini API
│   ├── tts_tool.py         ← gTTS صوت
│   └── video_tool.py       ← MoviePy مونتاج
└── output/                 ← الفيديوهات المنتجة
```

## ⚙️ الإعدادات (عبر /settings)

| الإعداد | الخيارات | الافتراضي |
|---------|---------|-----------|
| لغة الصوت | عربي / إنجليزي | عربي |
| لغة الترجمة | تلقائياً عكس الصوت | إنجليزي |
| عدد المشاهد | 3 / 5 / 7 | 5 |
